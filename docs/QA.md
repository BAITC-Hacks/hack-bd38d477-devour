# Протокол ручной проверки интерфейса

Источник контрольных значений: [README.md](../README.md), разделы «Демо за 5 минут», «Три контрольных сценария», «События», «AI: объяснение и советник» и «AI-аким». Числа ниже записаны с десятичной запятой. Статусы намеренно оставлены пустыми: это план проверки, а не отчёт о выполненных тестах.

Перед проверкой запустите приложение по README и откройте http://localhost:8000 либо проверяемую версию интерфейса. Запишите для себя адрес, версию приложения и браузер. Если явно не указано другое, выберите «Без события» и начните с нового набора. Для сравнения сохраняйте сценарии в одной вкладке без перезагрузки. Проверку без ключа выполняйте последней, после перезапуска сервера в соответствующем окружении.
