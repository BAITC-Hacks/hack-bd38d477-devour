# Дизайн-система web-v2 — «Аким на 5 часов»

## Идея
«Кабинет акима»: светлый, спокойный, дорогой городской дашборд. Главные герои — карта Астаны из 5 районов и большие цифры (Score, бюджет). Всё подчинено нашему сценарию: бюджет 100 → 5 решений → пересчёт районов → Score → объяснение AI → событие → AI-аким.

## Что берём из референсов (ничего не копируем 1:1)
- ref-sage.png — ОСНОВА: светлый шалфейный фон, стеклянные карточки, огромные тонкие цифры в плитках, карта с полупрозрачными кругами и тёмными кружками-цифрами, узкая панель иконок слева.
- ref-dark.png — только приём ленты событий с цветными чипами (шаги AI-акима, события). Тёмный фон НЕ берём.
- ref-game.png — только строки «иконка + подпись» на полупрозрачной подложке (каталог мер). Фото, логотип и шрифты игры НЕ берём.

## Токены — единственный источник цветов
```css
:root{
  --bg-1:#E6EEE1; --bg-2:#F5F3EB;
  --card:#FBFAF6; --glass:rgba(255,255,255,.72); --glass-border:rgba(255,255,255,.6);
  --ink:#1D3B35; --ink-2:#2B4F47; --muted:#6B7A72; --line:rgba(29,59,53,.10);
  --accent:#C9E27A;
  --score-crit:#E07A5F; --score-low:#E9C46A; --score-mid:#A8C98A; --score-good:#4F8A6E;
  --dir-T:#7FB3D5; --dir-E:#8FC18A; --dir-S:#E7B76B; --dir-B:#B79AD4; --dir-C:#6FA8A0;
  --shadow:0 10px 30px rgba(29,59,53,.08);
  --r-card:24px; --r-ctrl:14px; --r-pill:999px;
  --s1:4px; --s2:8px; --s3:16px; --s4:24px; --s5:32px; --s6:48px;
}
```
Правило: hex-цвета пишутся только в :root. Везде дальше — var(--…). Новые цвета не вводить.
Шкала балла: ниже 40 — --score-crit, 40–55 — --score-low, 55–65 — --score-mid, выше 65 — --score-good.
Направления: T транспорт, E экология, S соцсфера, B безопасность, C сервисы — цвета --dir-*.

## Типографика
Onest (Google Fonts, 300/400/500/700), запасной system-ui.
- display (Score, бюджет): 300, 72–96px, line-height 1;
- h1: 700, 36px; h2: 700, 22px; body: 400, 16px;
- label: 600, 12px, uppercase, letter-spacing .08em, цвет --muted.
  Десятичная запятая во всех числах.

## Поверхности
- страница: linear-gradient(160deg, var(--bg-1), var(--bg-2));
- .card: фон --card, радиус --r-card, padding --s4, тень --shadow;
- .glass: фон --glass, backdrop-filter: blur(16px), рамка 1px --glass-border;
- тёмная карточка (.card-ink): фон --ink, текст белый, акценты --accent — только для карточки Score в шапке и «записки советника».

## Компоненты (классы определяются в styles.css)
- .btn — высота 48px, радиус --r-ctrl, вес 600; .btn-primary — --ink + белый текст; .btn-accent — --accent + текст --ink (одно главное действие экрана: «Рассчитать», «Спросить AI-акима»); .btn-glass — стекло + текст --ink.
- .tile — плитка-метрика: label сверху, крупное число, подпись или дельта снизу (плюс — --score-good, минус — --score-crit).
- .chip — радиус --r-pill, padding 4px 12px, фон — цвет направления с прозрачностью 20% (color-mix), текст --ink.
- .dir-icon — круг 40px, фон — цвет направления 20%, иконка --ink (inline SVG).
- .measure-row — строка меры: .dir-icon + название + стоимость + лаг; выбранная — рамка 2px --accent.
- .step и .step-chip — лента шагов (AI-аким) и событий; чип validate — --dir-T, simulate — --dir-E, итог — --accent.
- .map-circle, .map-bubble, .map-river, .map-tooltip — элементы SVG-карты.
- .budget-seg — сегмент полосы бюджета, цвет направления.

## Макет
- слева вертикальная навигация 72px: круглые иконки 44px, активная — тёмный круг --ink с белой иконкой, подсказки при наведении; до 900px — нижняя полоса;
- контент: max-width 1320px, padding --s5;
- шапка экрана: слева label + h1, справа .card-ink с текущим Score (число --accent) и дельтой.

## Экраны
- Город (#city): слева карточки районов (большой балл, самый слабый показатель, число критических), справа #city-map — SVG-карта: река Есиль, 5 полупрозрачных кругов с радиальным градиентом цвета по баллу, тёмные кружки с баллом. Расположение: Сарыарка — северо-запад, Байконур — северо-восток, Алматы — восток, Есиль — юг за рекой, Нура — крайний юг.
- Решения (#decisions): меры .measure-row, сгруппированные по направлениям; справа закреплённая панель бюджета: крупный остаток и #budget-segments.
- Результат (#result): .tile с крупными числами (Score было → стало, бюджет, критические), анализ AI как «записка советника» в .card-ink, тепловые карты в шкале --score-*.
- Сравнение (#compare), Оптимизатор (#optimizer): карточки .card в едином стиле.
- События (#events): карточки с цветной полоской слева; выбранное событие — баннер сверху с новым бюджетом.
- AI-аким (#agent): поле цели, .btn-accent «Спросить AI-акима», лента .step, итоговая карточка с набором и кнопкой «Загрузить в решения».

## Контракт разметки и скриптов
- index.html (третья): сохраняет ВСЕ id и классы из web/index.html, которые использует /app.js. Добавляет пустые контейнеры: #city-map, #budget-segments, #agent-goal, #agent-run, #agent-status, #agent-steps, #agent-result. Крупные числа помечает data-countup.
- Скрипты в конце body: /app.js, затем /v2/map.js и /v2/agent.js (defer).
- map.js и agent.js (вторая): только наполняют эти контейнеры, используют классы из этого файла, свои цвета не вводят. Результаты расчёта получают через обёртку над window.fetch (ответы /api/state, /api/simulate, /api/explain), app.js не меняют.

## Нельзя
Новые цвета, шрифты и тени вне токенов; тёмный фон страницы; графика, логотипы и фото из референсов; изменения в web/.
