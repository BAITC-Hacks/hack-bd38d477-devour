# Дизайн-система web-v2 — «Астана. Новый день»

## Идея
Фотографическая Астана: тёмный сине-зелёный «петроль», молочный фон рабочих экранов и золото Байтерека. Главная собирается слоями: панорама → огромное «АСТАНА» → вырезанный Байтерек поверх букв → HTML-текст и кнопки. Жюри запоминает образ города, управленец легко читает рабочие экраны: на них фотографии занимают не больше четверти площади, главные — числа.

## Токены — единственный источник цветов
```css
:root {
  --bg:#F4F1E9; --surface:#FFFDF8; --surface-muted:#EAE9E1;
  --petrol:#102F35; --petrol-soft:#21464A; --text:#172E32; --text-muted:#586967; --text-on-dark:#F7F3E9; --border:#D8DDD5;
  --accent:#D4B978; --accent-hover:#E1C98F; --accent-text:#172E32; --sage:#BFD1AE;
  --positive:#376849; --positive-bg:#E5EEE2; --warning:#875D20; --warning-bg:#F5EAD3; --negative:#A04436; --negative-bg:#F7E5DF; --focus:#307D89;
  --font-ui:"Onest",Arial,sans-serif; --font-display:"Manrope","Onest",Arial,sans-serif;
  --text-sm:0.875rem; --text-base:1rem; --text-title:clamp(2rem,3vw,3rem); --text-score:clamp(3rem,5vw,4.5rem);
  --space-1:4px; --space-2:8px; --space-3:12px; --space-4:16px; --space-6:24px; --space-8:32px; --space-12:48px;
  --radius-control:8px; --radius-card:14px; --radius-hero:20px; --shadow-panel:0 12px 36px rgb(16 47 53 / 8%);
  --motion-fast:160ms; --motion-normal:280ms; --motion-city:1200ms; --ease-out:cubic-bezier(.22,1,.36,1);
}
```
Правило: hex-цвета пишутся только в `:root`, дальше — `var(--…)`. Для совместимости с `map.js` и `agent.js` в `:root` оставлены алиасы старых имён (`--ink`, `--ink-2`, `--line`, `--s2`, `--r-pill`, `--score-*`, `--dir-*`), они ссылаются на новую палитру.

Шкала балла: ниже 40 — `--negative` и слово «Критично», 40–55 — `--score-low`, 55–65 — `--score-mid`, выше 65 — `--positive`.
Направления: T транспорт, E экология, S соцсфера, B безопасность, C сервисы — цвета `--dir-*`.

## Типографика
Onest (400/500/600/700) — интерфейс; Manrope 800 — крупные заголовки, Score, бюджет и надпись «АСТАНА». Оба через Google Fonts, кириллица есть. Основной текст 16 px, вспомогательный 13–14 px, десятичная запятая во всех числах, `font-variant-numeric: tabular-nums` у чисел.

## Изображения
`web-v2/assets/`: `hero-city.jpg` (главная, панорама с Байтереком), `hero-result.jpg` (результат, Хан Шатыр и набережная), `hero-agent.jpg` (баннер AI-акима, вечерняя панорама), `dir-transport.jpg`, `dir-ecology.jpg`, `dir-social.jpg`, `dir-safety.jpg`, `dir-services.jpg` (карточки мер по направлению), `bayterek-cutout.png` (прозрачный слой над буквами). Изображения сгенерированы командой с помощью AI (ChatGPT) для этого проекта; hero до 1920 px по ширине, остальные до 900 px, каждое до 300 КБ. Текст внутри картинок не размещается.

Единая обработка: прохладные тени, тёплый свет, приглушённая зелень. До расчёта фото чуть приглушено (`filter: saturate(.82) brightness(.78)`), «оживание» — два наложенных световых слоя `.hero-light.cool` и `.hero-light.warm` с анимацией `opacity` за `--motion-city`. Никаких частиц и тряски экрана.

## Поверхности и компоненты
- страница: `--bg`; `.card` — `--surface`, рамка `--border`, радиус `--radius-card`, тень `--shadow-panel`;
- `.card-ink` — `--petrol` с текстом `--text-on-dark` и акцентами `--accent`: панель бюджета, «План действий» AI-акима, блок AI-анализа;
- `.btn` 46 px, `--radius-control`; `.btn-accent` — золотой, одно главное действие экрана («Начать управление», «Рассчитать», «Спросить AI-акима», «Применить сценарий»); `.btn-primary` — петроль; `.btn-glass` — молочный;
- `.measure` — карточка меры: фото направления сверху, название, эффекты, стоимость, «Начало эффекта: … квартал», выбор района; выбранная — рамка `--accent`;
- `.slot` — пять пронумерованных слотов решений в панели бюджета;
- `.event-toast`, `.event-topbar` — локальное уведомление о событии и плашка нового состояния; `.budget-loss` — отдельный сегмент потери бюджета;
- `.step`, `.step-chip` — лента настоящих шагов AI-акима (validate — `--dir-T`, simulate — `--dir-E`, итог — `--accent`);
- `.map-circle`, `.map-bubble`, `.map-river`, `.map-tooltip`, `.budget-seg` — элементы `map.js`.

## Макет
Верхняя горизонтальная навигация (sticky, петроль), контент до 1440 px с отступами 48 px, промежутки 24 px. Адаптив до 375 px: навигация переносится, hero и сетки складываются в одну колонку.

## Анимации
Переходы экранов — fade + сдвиг 12 px за `--motion-normal`, карточки появляются каскадом. После положительного результата: 0,4 с — тёплый свет на панораме, 1,2 с — насыщенность; Score считает `map.js` через `[data-countup]`. Ожидание API показано отдельно (`.hero-pending`). `prefers-reduced-motion` отключает всё.

## Контракт разметки и скриптов
- index.html сохраняет ВСЕ id и классы из `web/index.html`, которые использует `/app.js`, и контейнеры `#city-map`, `#budget-segments`, `#agent-goal`, `#agent-run`, `#agent-status`, `#agent-steps`, `#agent-result`.
- Скрипты в конце body: инлайн-скрипт витрины (слои, слоты, уведомления, обёртка над `window.fetch` с клонированием Response), затем `/app.js`, `/v2/map.js`, `/v2/agent.js` (defer). `app.js` не меняется.
- `map.js` и `agent.js` только наполняют свои контейнеры и используют классы из этого файла; свои цвета не вводят.

## Нельзя
Цвета, шрифты и тени вне токенов; текст внутри изображений; чужие фото и логотипы; имитация шагов AI таймерами; изменения в `web/`.
